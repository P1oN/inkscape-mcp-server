# Roadmap: Inkscape MCP для Codex на macOS

Согласован 2026-09-30. Основной сценарий: открыть рисунок в Inkscape, обсудить
изменения с Codex, увидеть результат и при необходимости отменить его.
Разработка ориентирована на работу художника в открытом документе.

## Текущее состояние

- Первый этап (выделение, изменение заливки, сохранение GUI между подключениями)
  объединён в `main`: PR #1.
- Чтение сцены и ограниченная вставка SVG объединены в `main`: PR #2.
- Вставка проверена через настоящий MCP STDIO с Inkscape 1.4.3 на macOS.
- Undo заливки проверен; Undo/Redo вставки простого фрагмента и фрагмента с градиентом
  проверены через интерфейс; содержимое SVG совпало с ожидаемым после каждого шага.
  Приёмка сохранения, переключения документов и ошибок завершена для проверенных
  тестовых рисунков.
- Document context (PR #4) и повседневные операции (PR #5) объединены в `main`.
- MCP startup/reconnect не открывают окно: для нового managed GUI требуется явный
  `live_launch()` по запросу пользователя либо CLI `--launch`.
- Инструкция и ограничения: [macOS prototype](../../live/macos-live-prototype.md).

Автоматические и CLI-проверки описаны в handoff; новой GUI-приёмки не было.

и их историческая приемка сохраняются.

## 1. Завершить проверку второго этапа — завершено 2026-09-30

  ранее существовавшие объекты сохранились.
- [x] Проверить Undo вставки с градиентом: вся группа, включая определение и ссылки,
  удалена одним Undo; отпечаток содержимого SVG совпал с состоянием до вставки.
- [x] Проверить, что один Redo возвращает простой фрагмент: группа восстановилась,
  отпечаток содержимого SVG совпал с состоянием после вставки.
- [x] Проверить Redo фрагмента с градиентом и внутренними ссылками: содержимое SVG,
  включая определение и ссылки, совпало с состоянием после вставки.
- [x] Сохранить через File → Save As (Inkscape SVG) и перезагрузить через File → Revert:
  содержимое файла и live SVG совпало с состоянием после вставки.
- [x] Проверить закрытие и повторное открытие сохранённого SVG: live SVG совпал
  с состоянием после вставки, включая градиент, ссылки и исходные объекты.
- [x] Проверить два окна и переключение активного документа: MCP прочитал объекты
  окна B, затем исходный рисунок после его закрытия и повторного открытия.
- [x] Проверить отказ при устаревшем контексте: принудительно неверный отпечаток
  вызвал отказ реального inkex-расширения; рисунок остался без изменений.
- [x] Проверить ошибки расширения и таймаут: семь автоматических сценариев проверяют
  очистку файлов запроса/ответа и следующий успешный вызов. Нативный отказ с диалогом
  воспроизвёл таймаут D-Bus; сервер теперь учитывает уже полученный ответ расширения.
- [x] Подтвердить восстановление обмена с нативной сессией после отказа: live SVG
  совпал с сохранённым рисунком; два новых подключения MCP STDIO прочитали сцену
  и сохранили тот же процесс Inkscape.
- [x] Закрыть повторный диалог отказа и проверить GUI: клавиша 5 изменила масштаб
  страницы с 25% до 60%; содержимое SVG осталось без изменений.

Критерий готовности: одна вставка полностью отменяется одним Undo и восстанавливается
одним Redo; отказ до применения не меняет рисунок. При таймауте сервер честно сообщает
неопределённость и предлагает проверить документ перед повтором.

Проверки проводить на отдельном тестовом рисунке. Для Undo/Redo сравнивать не только
картинку, но и экспортированный live SVG: состав группы, определения, ссылки и
сохранность ранее существовавших объектов. Зафиксировать результаты и версию Inkscape
в инструкции. Эта приёмка завершена; PR #2 уже объединён в `main`.

## 2. Предсказуемое подключение на macOS — завершено 2026-10-01

- [x] Актуальное имя рисунка в `live_status` и scene, проверка доступности шины,

- [x] Проверить обновление `live_status` при A → B → A через одно MCP-подключение
  на реальном GUI: проверено 2026-10-01, `connected_at` не изменился.
- [x] Реализованы список/выбор окна и runtime UUID окна/документа через GTK module.
- [x] Реализован guard внутри GUI перед GAction; выбранный для задачи рисунок
  должен совпадать с активным окном и документом.
- [x] Status различает потерю связи/отсутствие рисунка и сообщает восстановление;
  reconnect сохраняет GUI и сбрасывает выбор для задачи.
- [x] Финальная native acceptance нового launcher/guard на разблокированном Mac:
  `scripts/history/python/accept_document_context.py` прошел 2026-10-01 на Inkscape 1.4.3. Проверены
  одинаковые SVG с разными ID, явный выбор, Undo/Redo, race/stale-binding refusal
  и STDIO reuse. [Состояние и ограничения](../../live/document-context.md).

PR #4 объединён в `main` 2026-10-01; интеграция остается экспериментальной.
Rust migration отложена: native integration потребовала дополнительных работ и выявила
проблемы старта/активации на macOS. Условие миграции без проблем не выполнено.

Критерий готовности: Codex однозначно сообщает, какой рисунок читает и изменяет.

## 3. Повседневные операции — объединено в main (PR #5), 2026-10-01

- [x] Заливка, обводка и прозрачность: несколько свойств/объектов за один вызов.
- [x] Изменение существующего однострочного текста с одним текстовым run, без потери
  оформления и позиции. Смешанное оформление, textPath и flowed text явно отклоняются.
- [x] Перемещение, масштабирование и вращение в координатах документа; масштабирование
  и вращение вокруг начала координат документа.
- [x] Дублирование с новыми ID и переназначением внутренних ссылок, удаление, группировка,
  разгруппировка простых групп, порядок объектов в пределах родителя.
- [x] Учёт блокировок объектов/слоёв и преобразований слоёв. Сингулярные преобразования,
  CSS transform и вложенные SVG viewport отклоняются без изменения рисунка.
- [x] Документированное поведение Undo: один изменяющий вызов — один native Undo;
  вызов без изменения не добавляет шаг. Нативная проверка проходит через MCP STDIO.

Поддерживаемый объем и границы: [everyday edits](../../live/everyday-edits.md). Группировка требует
соседних объектов одного родителя; удаление используемых другими объектами ID отклоняется;
разгруппировка групп с эффектами/унаследованным стилем и структурные правки при наличии
stylesheet требуют подготовки рисунка. Эти случаи не упрощаются автоматически.

Критерий готовности: типичные правки иллюстрации выполняются без ручного изменения
XML и имеют предсказуемую отмену.

Первая часть проверена на копии реального `background.svg` через native GUI/MCP STDIO:
перемещение дерева, прозрачность группы цветов, дублирование и точный Undo/Redo.
Объем, ограничения и воспроизведение: [live discovery](../../live/live-discovery.md).
Этап 4 целиком пока не завершён.

Критерий готовности: Codex надёжно находит элементы по просьбе вроде
«сделай дальние холмы светлее»; неоднозначность приводит к уточнению.

## Приоритеты и архитектура

Ближайший релиз ограничен этапами 1–3; затем проверить удобство на реальных работах.
Переход на Rust рассматривать после пилота при наличии конкретной причины.
Смена языка сама по себе не решает выбор документа, интеграцию с Inkscape и Undo.
Оценки сроков уточнять после приёмки каждого этапа.
